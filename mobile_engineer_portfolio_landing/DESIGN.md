## Brand & Style

This design system blends **Obsidian High-Tech Dark Mode** with refined **Cyber-Glassmorphism**, architected specifically for senior-level engineering portfolios, developer platforms, and technical architecture showcases. 

The aesthetic is anchored in an abyss of deep slate and obsidian surfaces, punctuated by hyper-precise, neon-luminescent signals: Electric Indigo for primary interactions, Cyber Cyan for high-tech focus and active glows, and Emerald Green for system telemetry, live statuses, and availability indicators. Frosted glass interfaces (translucent surface layering, subtle structural outlines, and directional ambient back-glows) project elite craft, technical depth, and modern engineering prowess without descending into chaotic clutter or legibility trade-offs.

Target users and technical recruiters encounter an environment that feels like an advanced IDE or mission control interface: authoritative, surgically precise, high-contrast, and performant.

## Colors

The system relies on an uncompromising dark canvas architecture designed to simulate high-density, low-latency development dashboards.

- **Primary (`#6366f1` - Electric Indigo):** Anchors main interactive touchpoints, high-priority actions, brand declarations, and gradient accents.
- **Secondary (`#06b6d4` - Cyber Cyan):** Deployed for highlights, tech stack telemetry, active code-block markers, link hovers, and high-energy luminescent states.
- **Tertiary (`#10b981` - Emerald Green):** Dedicated strictly to live state indicators, availability badges ("Open to Work", "Live Project"), and build/pipeline status metrics.
- **Neutral (`#09090b` - Obsidian Black):** The deepest foundation layer. Layered variations like `#0f172a` (Slate 900) form structured inner surfaces.
- **Translucency & Glass Borders:** Key glass interfaces utilize `rgba(15, 23, 42, 0.65)` layered over canvas noise or radial gradient blooms, bound by crisp, whisper-thin borders (`rgba(255, 255, 255, 0.10)`), with directional edge highlights shifting toward `rgba(6, 182, 212, 0.35)`.

## Typography

The typographic hierarchy establishes a dialogue between human-centric geometric clarity and industrial developer instrumentation:

- **Headlines (Plus Jakarta Sans):** Crafted with tight tracking, distinct geometric counters, and decisive boldness (`600` to `800`). It introduces forward momentum and polished presentation to technical titles.
- **Body & Structural Text (Inter):** Highly legible, neutral workhorse engineered for rapid reading across long technical case studies, project overviews, and mobile-friendly system documentation.
- **System Tags, Architecture Badges & Code Blocks (JetBrains Mono):** Injected intentionally into tags, metadata, metrics, API parameters, and architecture callouts. Always styled with uppercase or monospace formatting to enforce an engineered vibe.

## Layout & Spacing

The layout model is anchored on a 12-column responsive fluid grid with strict maximum container bounds (`1280px` max-width) to preserve readability and architectural balance.

- **Desktop (>= 1024px):** 12 columns with `1.5rem` (`24px`) gutters and `3rem` (`48px`) outer margin. Section spacing expands to `6rem` (`96px`) to allow glass cards room to breathe against glowing ambient backdrop layers.
- **Tablet (768px - 1023px):** 8 columns with `1.5rem` gutters and `2rem` outer margin. Dual-column project layouts collapse into single column priority views where needed.
- **Mobile (< 768px):** 4 columns with `1rem` (`16px`) gutters and `1rem` safe margins. Glass panels discard multi-axis tilt interactions and adopt full-width stacked configurations.

## Elevation & Depth

Visual depth does not use murky drop shadows. Instead, it relies on **Cyber-Glassmorphism** combined with **Specular Light Scattering and Colored Ambient Halos**:

1. **Surface 0 (Canvas):** Base background `#09090b`. Features fixed, subtle radial gradients (`radial-gradient(circle at 50% 0%, rgba(99, 102, 241, 0.12), transparent 50%)`).
2. **Surface 1 (Base Frosted Glass):** Background `rgba(15, 23, 42, 0.60)` with `backdrop-filter: blur(20px)`. Outer outline: `1px solid rgba(255, 255, 255, 0.08)`.
3. **Surface 2 (Elevated / Interactive Cards):** Background `rgba(15, 23, 42, 0.75)` with `backdrop-filter: blur(24px)`. Outer outline: `1px solid rgba(255, 255, 255, 0.12)`. Ambient glow: `box-shadow: 0 8px 32px -4px rgba(0, 0, 0, 0.5), 0 0 16px -2px rgba(6, 182, 212, 0.15)`.
4. **Surface 3 (Overlays, Modals, Popovers):** Background `rgba(9, 9, 11, 0.88)` with `backdrop-filter: blur(32px)`. Outlines use subtle top-edge specular highlights (`1px solid rgba(255, 255, 255, 0.20)`).
5. **Interactive Glow Hover State:** On hover, card borders smoothly transition to `rgba(6, 182, 212, 0.50)` with a directional cyan-to-indigo shadow burst (`box-shadow: 0 0 24px -4px rgba(6, 182, 212, 0.35)`).

## Shapes

The design system maintains **Level 2 (Rounded)** architecture (`0.5rem` or `8px` base, `1rem` or `16px` for standard glass containers, and `1.5rem` or `24px` for hero shells and featured case study frames). 

Small chips, code badges, and system telemetry indicators employ strict `rounded-md` (`6px`) or full pill shapes (`rounded-full`) exclusively when representing binary status pills (e.g., pulsing live indicators). The crisp boundary geometry prevents glass containers from looking squishy or gelatinous, maintaining the discipline expected in a senior engineer's workstation.

## Components

### Buttons
- **Primary Cyber Button:** Background in `rgb(99, 102, 241)` with an inset micro-gradient highlight. Text in pure white, weight `600`. Hover state triggers a bloom effect with `box-shadow: 0 0 20px rgba(99, 102, 241, 0.5)` and a subtle scale shift (`scale(1.02)`).
- **Secondary Glass Button:** Translucent slate background (`rgba(255, 255, 255, 0.05)`), border `1px solid rgba(255, 255, 255, 0.15)`, text `text-slate-200`. Hover state transitions the border to Cyber Cyan (`#06b6d4`) with subtle back-blur reinforcement.

### Glass Cards & Project Shells
- Cards feature `backdrop-blur-xl`, `border border-white/10`, and a background of `rgba(15, 23, 42, 0.65)`.
- Cards utilize a top specular shine: a subtle 1px gradient stroke across the top border running from transparent -> `rgba(255, 255, 255, 0.25)` -> transparent.
- Interactive project showcase cards include an internal tech stack footer displaying tags styled with JetBrains Mono.

### Status Indicators & Badges
- **Live Status (Tertiary / Emerald):** A pill-shaped capsule (`border border-emerald-500/30`, background `rgba(16, 185, 129, 0.10)`). Houses a pinging radar dot: an inner solid green circle (`#10b981`) enveloped by an animated CSS pulse wave (`rgba(16, 185, 129, 0.40)`).
- **Architecture & System Chips:** Monospace text (`mono-tag`), background `rgba(255, 255, 255, 0.04)`, border `1px solid rgba(255, 255, 255, 0.08)`, text color Cyber Cyan or light slate.

### Inputs & Terminal Fields
- Dark input fields using `rgba(9, 9, 11, 0.75)` with `border border-white/10`. On focus, the border becomes `#6366f1` with an outer cyan glow ring (`box-shadow: 0 0 0 3px rgba(6, 182, 212, 0.20)`). Placeholder text in muted slate (`#64748b`).

### Code Snippets & Architecture Toggles
- Embedded code previewers feature a tabbed header bar with mock OS controls (close, minimize, expand in subdued monochrome or subtle color), JetBrains Mono typography, custom cyan scrollbars, and line-number gutters separated by a `1px` translucent border.
